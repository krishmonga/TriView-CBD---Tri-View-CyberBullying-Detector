## Submission format

IJ-AI prefers their **Word or LaTeX template** from the journal website.

### Option A — LaTeX draft (start here)

```bash
cd paper/journal_submissions/06_IAES_IJ-AI
pdflatex TriFuse.tex && pdflatex TriFuse.tex
```

Then copy content into the official IJ-AI Word/LaTeX template from the portal.

### Option B — PDF upload

Compile `TriFuse.tex` and upload PDF + source if portal allows.
